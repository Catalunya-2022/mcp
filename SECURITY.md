# Política de seguretat / Security Policy

## Com informar d'una vulnerabilitat / Reporting a vulnerability

Si trobes una vulnerabilitat en aquest codi o al servidor públic `mcp.2022.cat`, informa'n de manera privada mitjançant [GitHub Security Advisories](https://github.com/catalunya-2022/mcp/security/advisories/new). No obris issues públiques per a informes de seguretat.

If you find a vulnerability in this code or in the public server at `mcp.2022.cat`, report it privately via [GitHub Security Advisories](https://github.com/catalunya-2022/mcp/security/advisories/new). Please do not open public issues for security reports.

- Confirmarem la recepció en pocs dies laborables. / We will acknowledge receipt within a few working days.
- No hi ha programa de recompenses. / There is no bounty program.

## Abast / Scope

- Aquest repositori i el desplegament públic a `https://mcp.2022.cat`. / This repository and the public deployment at `https://mcp.2022.cat`.
- El servidor no té autenticació ni emmagatzema dades d'usuaris: serveix únicament un document públic de 2021 en mode lectura. / The server has no authentication and stores no user data: it serves a public 2021 document, read-only.
- Per al lloc web (`2022.cat`), fes servir el [repositori web](https://github.com/catalunya-2022/web). / For the website (`2022.cat`), use the [web repository](https://github.com/catalunya-2022/web).

## Versions suportades / Supported versions

Només la branca `main` i el desplegament de producció actual. / Only the `main` branch and the current production deployment.
